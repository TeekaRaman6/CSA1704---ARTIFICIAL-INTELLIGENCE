## ▶️ How to Run the Code

### Requirements
- Python 3.8+
- `matplotlib`
- `networkx`

### Install dependencies
```bash
pip install matplotlib networkx
```

### Run
```bash
python3 ai_scenario_solutions.py
```

This will:
1. Print a clearly labelled console report for every scenario (paths, costs, nodes expanded,
   timetables, pruning statistics, etc.).
2. Generate `output.png` — a 6-panel figure summarizing every scenario's result.

**Expected runtime:** under 2 seconds on a standard machine. No internet access or external
data files are required — every test case (graph, cost landscape, terrain, course list, game
board) is defined inside the script.
